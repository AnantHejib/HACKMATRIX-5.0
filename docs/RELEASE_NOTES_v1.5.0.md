# FIN v1.5.0 - Transparent Action Impact

This release adds the remaining expected-output requirements to the financial-health prototype.

## New in this release

- Quantified expected impact for every generated recommendation
- Monthly and six-month outcome estimates with confidence and limitations
- A decision brief that clearly separates observed facts, model predictions, and recommendations
- Structured Ask FIN answers using the same fact/prediction/recommendation boundaries
- A change simulator for income, expenses, debt, and liquid savings
- Automatic before/after comparison after CSV imports, category corrections, and financial-history updates
- Visible changes to health score, cash-gap risk, safe-to-spend, debt, and the leading action
