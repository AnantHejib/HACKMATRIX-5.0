# FIN v1.4.0 - Personalized Financial Copilot

This release completes the hackathon prototype from onboarding to explainable action.

## Highlights

- Consolidated financial-health dashboard from transactions and financial history
- Net worth, savings rate, emergency runway, debt pressure, and credit utilization
- Spending-trend and recurring-obligation detection
- 500-path probabilistic 30-day cash-flow forecast with P10/P50/P90 bands
- Personalized Ask FIN conversations and saved recommendations
- Optional OpenRouter `openrouter/free` connection with no key embedded in the APK
- Passwordless demo login, local sessions, CSV import, evidence records, and audit trail
